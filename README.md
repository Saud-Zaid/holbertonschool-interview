# Holberton School - Interview Preparation

This repository contains interview preparation projects and algorithm solutions.

## Projects

| Directory | Project | Description |
| --------- | ------- | ----------- |
| [pascal_triangle](./pascal_triangle) | Pascal's Triangle | Python implementation of Pascal's Triangle algorithm |
| [lockboxes](./lockboxes) | Lockboxes | Python algorithm to determine if all locked boxes can be opened |
| [minimum_operations](./minimum_operations) | Minimum Operations | Calculates fewest number of operations to reach n H characters |
| [log_parsing](./log_parsing) | Log Parsing | Real-time stdin log parsing and metrics computation |
| [utf8_validation](./utf8_validation) | UTF-8 Validation | Validation method for UTF-8 encoded data sets |
| [nqueens](./nqueens) | N Queens | Backtracking algorithm to solve the N queens problem |
| [rotate_2d_matrix](./rotate_2d_matrix) | Rotate 2D Matrix | In-place algorithm to rotate an n x n 2D matrix 90 degrees clockwise |
| [making_change](./making_change) | Making Change | Fewest number of coins needed to meet a given total amount |
